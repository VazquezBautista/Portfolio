## Selected Projects

### [SME Operations Platform](projects/sme-operations-platform.md)
A full-stack platform designed to centralize and digitalize the operation of small and medium-sized businesses. It brings together online and in-person sales, inventory, purchasing, post-sales workflows, integrations, document generation, printing, and operational controls in a single system.

**Highlights:** extensible external-service integrations, cloud-to-local printing architecture, PostgreSQL schema lifecycle with Alembic, automated testing, auditability, and Google Cloud deployment.

**Core stack:** Python · Flask · React · PostgreSQL · SQLAlchemy · Alembic · Docker · Google Cloud  
**Live deployment:** [Ida y Vuelta DECO](https://idayvueltadeco.com)

### [ADF Servicios VIP](projects/adf-servicios-vip.md)
A web platform built for a real transportation and tourism services company. It combines an internet presence with an operational management system that centralizes services, drivers, vehicles, agencies, role-based access, and traceability.

**Highlights:** real business-process modeling, role-based authorization, chronological service management, REST API, containerized deployment, and migration from SQL Server to PostgreSQL.

**Core stack:** Python · Flask · React · PostgreSQL · SQLAlchemy · Docker · Google Cloud  
**Deployment:** [adfservicios.com](https://adfservicios.com)
